# UX/UI Framework

Набор агентов и навыков Codex для проектирования UX/UI веб-сайтов. На входе — бриф, на выходе — исследование, UX-спецификация, дизайн-система, работающий прототип и отчёт аудита.

## Как работает пайплайн

[Code First](workflows/uxui-code-first.md) идёт от Discovery через Research, UX и UI к независимому QA. Основная сессия Codex уточняет недостающие данные, проверяет результаты агентов и сохраняет принятые этапы в `docs/design/.workflow-state.json`. После изменений воркфлоу возобновляется с первого затронутого этапа. Блокирующие дефекты возвращаются ответственным агентам, а QA повторяет проверки.

`docs/design/design-system.md` задаёт токены с точными значениями, визуальные принципы, правила адаптации и контракты компонентов. Компоненты описываются по назначению, вариантам, состояниям и поведению, независимо от имён и расположения файлов. Код следует документу, а QA отмечает расхождения. Ссылка из `AGENTS.md` помогает Codex учесть эти правила в будущих задачах по сайту.

## Агенты и навыки

| Агент | Задача | Результат (`.md` в `docs/design/`) | Подходящие навыки |
| --- | --- | --- | --- |
| [Discovery Specialist](.codex/agents/discovery-specialist.toml) | Уточняет цели, требования и допущения | `brief.md` | — |
| [Design Researcher](.codex/agents/design-researcher.toml) | Изучает аудиторию, конкурентов и референсы, отделяет наблюдения от гипотез | `research.md` | `ux-research-discovery-testing` |
| [UX Designer](.codex/agents/ux-designer.toml) | Проектирует структуру сайта, сценарии и взаимодействия | `ux-spec.md` | `product-design-and-ux` |
| [UI Designer](.codex/agents/ui-designer.toml) | Разрабатывает визуальную концепцию, компоненты и адаптивный интерфейс | `design-system.md` и работающий прототип | `ui-ux-pro-max`, `frontend-design` |
| [Design QA](.codex/agents/design-qa.toml) | Независимо проверяет UX, доступность, адаптивность, визуальную согласованность и соответствие требованиям | `qa-report.md` с находками и рекомендациями | `evaluate`, `web-accessibility`, `web-design-guidelines` при наличии кода |

## Установка и запуск

На Linux, macOS или WSL нужны Codex, Bash, Python 3.11+, Node.js 22.20+ с `npx`, Git и доступ к npm и GitHub. Укажите существующий каталог сайта. [Установщик](scripts/install-skills.sh) восстановит навыки из [skills-lock.json](skills-lock.json), добавит UI/UX Pro Max и установит пять ролей, воркфлоу и утилиту состояния в проект сайта.

```bash
bash /path/to/ux-ui-framework/scripts/install-skills.sh --target /path/to/site
cd /path/to/site
codex
```

В новой сессии Codex, открытой из корня сайта, передайте путь к брифу и попросите запустить воркфлоу.

> Выполни `.codex/ux-ui-framework/workflow.md` для брифа `docs/site-brief.md` и вызови указанных в нём субагентов.

Для обновления выполните ту же команду установки. Управляемые пути перечислены в `.codex/ux-ui-framework-install.json`. Если сайт уже использует один из этих путей для своей роли или навыка, установщик укажет конфликт перед записью. Вызов без `--target` устанавливает только навыки в сам репозиторий фреймворка.

При возобновлении укажите тот же воркфлоу. Текущий статус можно посмотреть из корня сайта командой `python3 .codex/ux-ui-framework/workflow-state.py status`. Утилита сверяет снимки принятых файлов, а содержимое и результаты проверок принимает основная сессия.
